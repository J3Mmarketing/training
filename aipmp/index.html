公文常見錯誤與 AI 輔助修正

常見錯誤正確作法Gemini 協助方式
主旨超過兩行、過於冗長主旨一段話、簡潔有力「請將以下主旨精簡為 50 字以內」
說明與辦法混用說明交代背景、辦法列請辦事項「請重新分段，說明只寫背景，辦法只寫請辦事項」
敬語錯誤（鑒核 vs 查照）上行用鑒核，平行/下行用查照「受文者是○○，請確認結尾敬語是否正確」
條號格式不一致統一用一、二、三，子項用（一）（二）「請統一條號格式」

Step 2 — 從簡章 PDF 提煉文字內容

提煉提示詞（上傳簡章 PDF 後使用）
從「職前訓練網簡章.pdf」檔案中，依照下列格式提煉出所有必要資訊：

【主標區域】班名（大標）、副標題（15–20 字）
【時程資訊】培訓日期、上課時間
【課程特色】5 點，每點不超過 8 字
【課程資訊】報名期間、上課地點、招生對象：15 歲以上具工作意願之失業者、特定身分：免費參訓＋協助申請生活津貼
【報名方式】主辦單位、報名地點、電話
行銷文案版（提煉後再生成）
請為以上職業訓練課程製作招生 DM 文案。受眾：正在求職的失業者。核心訴求：免費學習、快速就業、有政府補助。
請產出：①主標題（10 字內，吸睛有力）②副標題（20 字內）③3 個重點 bullet ④行動呼籲（報名截止日）。語氣：溫暖積極，避免制式官方語氣。
社群貼文版（Facebook / LINE）
請將以上 DM 文案改寫為 Facebook 貼文格式，加上適當的 emoji 和段落，控制在 150 字以內，結尾加 hashtag。

方法一 — 數據分析（Word + Claude）

將執行成果數據整理至 Word 文件後，透過 Word 內建的 Claude 功能，直接在文件中進行數據分析與報告撰寫，無需切換工具。

如何在 Word 中使用 Claude

➊ 開啟 Word 文件，點選上方功能列的「常用」或「插入」頁籤，找到「Copilot / Claude」入口。
➋ 在側邊欄輸入提示詞，Claude 會直接讀取文件內容並回應。
➌ 可選取文件中的數據區塊，右鍵選「使用 Claude 分析」，快速取得摘要與建議。

數據分析應用情境

將結訓人數、就業率、滿意度、經費執行率等數字填入 Word 表格後，請 Claude 自動計算達標率、比較目標值與實際值，並生成文字說明，直接套用至報告書對應項目。

Word + Claude 數據分析提示詞範本
在 Word 中框選需要分析的數據區塊，於 Claude 側邊欄貼入原始數據後，輸入以下提示詞，請 Claude 依照報告書表格格式產出：

以下是本班執行成果原始數據，請依照報告書表格格式整理並產出，欄位包含：項目名稱、目標值、實際數據、達標判斷（✓達標 / ⚠️未達標）、說明備註。

方法二 — 九項檢討 Gemini 生成提示詞

方法三 — 互動式儀表板（Gemini Canvas）

將學員基本資料整理完成後，使用 Gemini Canvas 建立互動式儀表板，視覺化呈現性別、年齡、教育程度與就業關聯性分析，供簡報或審查會議直接使用。

操作方式

➊ 開啟 Gemini，切換至 Canvas 模式。
➋ 貼上學員名冊數據（姓名可去識別化），說明分析需求。
➌ Gemini 自動生成含互動篩選功能的 HTML 儀表板，可直接於瀏覽器操作。
➍ 調整色系或欄位後，使用下方匯出提示詞輸出 PNG 圖片。

分析維度說明

性別分布：男女比例圓餅圖，對應報告書七(一)。
年齡層分布：長條圖分層呈現，對應七(二)。
教育程度：各學歷人數比較，對應七(三)。
就業關聯性：交叉分析就業與未就業學員在各維度的分布差異，供九項檢討使用。

方法四 — Office Agent 寫報告

數據分析完成後，使用 Microsoft 365 的 Office Agent 功能，直接在 Word 中將已整理的數據與 Gemini 產出的文字段落，一鍵整合為符合格式的完整報告書。

Office Agent 操作步驟

➊ 開啟 Word，點選功能列「常用」→「Copilot」開啟側邊欄。
➋ 上傳或貼入學員數據表及 Gemini 生成的文字段落。
➌ 指定報告書格式與章節架構，請 Agent 自動排版填入。
➍ 逐項確認數字無誤後，套用公文字型輸出最終版本。

適用情境

適合已備妥數據與文字素材、需快速完成報告書排版的情境。Office Agent 可自動識別欄位對應關係，大幅減少人工複製貼上的錯誤率，尤其適用於第六、七、九、十項需要大量文字整合的段落。
