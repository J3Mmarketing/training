03 · VIBE CODING · 3 份教材

Vibe Coding 與 3D 互動設計．

以前想做一個理財試算器、報名表單、互動小遊戲，甚至能 360 度旋轉的 3D 展示網頁，都得找工程師或學建模軟體。現在用 Vibe Coding，你只要把需求用白話文講清楚，就能跟 AI 對話做出能直接使用的工具與響應式網頁，還能做出讓照片走進立體攝影棚的 3D 互動網站，最後安全發布成公開網址分享給別人。

本節大綱
  1. ➊Vibe Coding 實作小工具：從隨興試玩到有規劃地寫規格，用對話做出理財試算器、互動小遊戲與 42 種表單元件
  2. ➋跨界網頁與客製化開發：進階設計企業級響應式網頁與能記住資料的輕量應用，建立防呆與資料結構觀念
  3. ➌3D 互動設計：不用學 3D 建模軟體，用對話做出 Three.js 空間環景提案與 3D 攝影棚互動網站
  4. ➍上架發布與資安檢查：透過 Gemini Canvas、Google AI Studio、Google 協作平台或 GitHub Pages 上線，並做上線前資安檢查

Vibe Coding 與 3D 互動設計常見問題

完全不會寫程式，真的做得出來嗎？

可以。Vibe Coding 的重點是用白話文描述你要的功能、畫面和修改方向，讓 AI 幫你寫出程式並即時預覽。我還會教你「先寫說明書再動手」的做法，讓做出來的東西更穩定、不會改一改就壞掉。

做好的小工具或 3D 網頁可以放哪裡給別人用？

課程會帶你走過三條常見的上架路線：用 Gemini Canvas 直接分享連結、用 Google AI Studio 一鍵發布，或是放到 Google 協作平台與 GitHub Pages，並附上課堂整理的「上架前資安檢查清單」，確認金鑰和個資沒有外露再公開。

不懂 3D 建模軟體也能做 3D 互動網頁嗎？

可以。就像網站一樣，只要用對話把空間配置、視角、材質或攝影棚姿勢說清楚，AI 就能用 Three.js 產出可以旋轉、縮放的 3D 互動畫面。
