    建立範本副本

    Google 試算表 · 約需一個 Google 帳號

    需要Google 帳號
    完成後你會有自己的試算表，上方多一個「🤖 LINE 助理」選單
    1. 打開範本：LINE AI 案件助理（學員範本）↗，點上方「檔案」→「建立副本」或直接點 建立副本連結 ↗，會直接跳出「建立副本」按鈕
    2. 副本名稱改成自己的名字，例如「王小明｜LINE 助理資料庫」
    3. 打開副本等 5～10 秒，上方選單列「說明」右邊出現「🤖 LINE 助理」
    ✓ 怎麼確認做對了
    • 下方有「案件進度」「待辦與提醒」「收支紀錄」三個分頁，每頁第一列都有標題
    • 上方看得到「🤖 LINE 助理」選單
    看不到「🤖 LINE 助理」選單？
    1. 重新整理頁面，等 5～10 秒
    2. 還是沒有：點「擴充功能」→「Apps Script」，函式下拉選單選 onOpen 按「執行」，照畫面授權後切回試算表
    不用範本，自己從頭建立

    適合想了解每個環節的人。做完這裡再接 STEP 2，並在 STEP 5 之前把程式碼貼進 Apps Script（程式碼在頁面最下方「完整程式碼」）。

    1. Google 雲端硬碟 →「新增」→「Google 試算表」，改名「LINE AI 助理資料庫」
    2. 點選單列「Gemini」，貼上下方提示詞，讓 Gemini 建好三個工作表。沒有 Gemini 選單就手動新增分頁，名稱與標題照提示詞打字
    3. 「擴充功能」→「Apps Script」，左側齒輪「專案設定」時區選「(GMT+08:00) 台北」
    4. 回到 程式碼.gs，刪掉預設內容，貼上完整程式碼，按儲存，回試算表重新整理

    02

    建立專屬 LINE 官方帳號，啟用 Messaging API

    LINE Official Account Manager · tw.linebiz.com ↗

    需要你的私人 LINE 帳號
    完成後你會有一個全新官方帳號，已加為好友、Webhook 已啟用
    不可用公司對客戶的官方帳號。Webhook 一綁定，所有客戶傳來的訊息都會被送進 AI、記進你的試算表，客戶也收不到原本的自動回覆。每個人自己新建一個。
    1. 用私人 LINE 登入 LINE Official Account Manager ↗，點「建立官方帳號」帳號名稱例如「專案管理助理」；類別選接近的即可，不影響功能
    2. 後台右上角「設定」→ 左側「Messaging API」→「啟用 Messaging API」服務提供者（Provider）填英文或公司簡稱，例如 KitchenCRM；隱私權政策可留空
    3. 左側「回應設定」：「自動回應訊息」切成停用，「Webhook」切成啟用不關自動回應，每則訊息都會先收到一句官方罐頭訊息
    4. 左側「增加好友人數」→「增加好友工具」→「建立加入好友行動條碼」，用手機掃描加好友
    ✓ 怎麼確認做對了
    • 「回應設定」：自動回應訊息停用、Webhook 啟用
    • 手機 LINE 好友清單裡有這個官方帳號
    Webhook 開關是灰色、打不開？

    畫面寫「啟用 Messaging API 後即可使用此功能」，代表第 2 小步還沒做完。先回「Messaging API」啟用，再回來打開。

    03

    取得 Channel access token 與 User ID

    LINE Developers Console · developers.line.biz/console ↗

    需要STEP 2 建立的官方帳號
    完成後你會有記事本裡的 Channel access token、U 開頭的 User ID
    1. 打開 LINE Developers Console ↗，點進 STEP 2 建立的 Provider，再點進同名的 Channel也可以從官方帳號後台「Messaging API」頁最下方的連結進來
    2. 切到「Messaging API」分頁，捲到最下方「Channel access token (long-lived)」，點「Issue」，再點「Copy」貼到記事本
    3. 同一頁找到「Webhook redelivery」並關閉避免同一則訊息被記錄兩次
    4. 切到「Basic settings」分頁，捲到最下方「Your user ID」（U 開頭），點「Copy」貼到記事本
    Channel access token 等於密碼。任何人拿到都能用你的官方帳號發訊息。不要截圖、不要貼群組；外流時回同一處按 Reissue 重新發行，舊的就會失效。
    ✓ 怎麼確認做對了
    • 記事本有一長串 Channel access token
    • 記事本有一串 U 開頭、共 33 個字的 User ID
    04

    申請 Gemini API Key

    Google AI Studio · aistudio.google.com ↗

    需要Google 帳號
    完成後你會有記事本裡的 Gemini API Key
    1. 打開 Google AI Studio ↗，點左側「Get API key」→「Create API key」
    2. Name your key 填「案件助理」，Choose an imported project 選「Default Gemini Project」，點「Create key」
    3. 複製金鑰貼到記事本
    金鑰等同密碼。每個學員用自己的金鑰，費用與額度都算在自己的帳號；免費方案超過上限只會暫時失敗，不會計費。
    05

    用選單填入三組金鑰

    你的試算表 ·「🤖 LINE 助理」→「① 填入金鑰」

    需要記事本裡的 Token、User ID、Gemini API Key
    完成後你會有金鑰存進這份試算表，不用改程式碼
    1. 回到試算表，點「🤖 LINE 助理」→「① 填入金鑰」
    2. 第一次使用會跳出「需要授權」，點「審查權限」並選你的帳號出現「Google 尚未驗證這個應用程式」：點左下「進階」→「前往…（不安全）」→「允許」。這是你自己建立的程式還沒送 Google 審核，不是中毒
    3. 依序貼上 Channel access token、User ID、Gemini API Key，每貼一組按「確定」已經填過的只顯示頭尾幾個字，不改就直接按「確定」
    4. 出現「✅ 金鑰已儲存」就完成
    金鑰存在這份試算表的 Apps Script 專案設定裡，不會出現在程式碼或表格。別人建立你這份試算表的副本，也讀不到你的金鑰。
    貼上後說「看起來不對」？
    • User ID 要是 U 開頭、共 33 個英數字，別貼成 Channel ID
    • Token 長度太短：回 STEP 3 重新點 Copy，不要用滑鼠選取
    • 不能有空白或換行：貼上前先貼到記事本確認
    06

    部署為網頁應用程式

    Apps Script 編輯器 ·「擴充功能」→「Apps Script」

    需要STEP 1 的試算表
    完成後你會有結尾是 /exec 的網頁應用程式網址
    1. 在試算表點「擴充功能」→「Apps Script」，右上角藍色「部署」→「新增部署作業」
    2. 「選取類型」旁的齒輪選「網頁應用程式」
      • 執行身分：我
      • 誰可以存取：所有人
    3. 點「部署」，跳出授權就點「審查權限」並允許
    4. 複製「網頁應用程式」網址（結尾是 /exec）貼到記事本
    「誰可以存取」一定要選「所有人」，LINE 才進得來。選「只有我自己」或「所有具備 Google 帳戶的使用者」，傳訊息會完全沒反應。
    之後改了程式碼或流程規則，要重新部署嗎？

    要。只按儲存不會生效：「部署」→「管理部署作業」→ 右上鉛筆「編輯」→ 版本選「新版本」→「部署」。網址不會變，不用重設 Webhook。

    07

    一鍵設定與測試

    你的試算表 ·「🤖 LINE 助理」→「② 一鍵設定與測試」

    需要STEP 5 的金鑰、STEP 6 的 /exec 網址
    完成後你會有五項全 ✅：LINE、Gemini、提醒排程、Webhook 都接好
    1. 回到試算表，點「🤖 LINE 助理」→「② 一鍵設定與測試」
    2. 跳出「要把 LINE 的 Webhook 設成這個網址嗎？」：網址和 STEP 6 的一樣就按「是」不一樣就按「否」，貼上 STEP 6 結尾是 /exec 的網址
    3. 等 10～30 秒，跳出「② 一鍵設定結果」，手機也會收到一則測試推播
    ✓ 五項都要是 ✅
    • 三個工作表都在
    • 推播成功，請看手機 LINE
    • Gemini 連線成功
    • 已建立兩個觸發條件：每天早上 7 點推播、每 5 分鐘檢查 ⏰ 提醒
    • Webhook 已自動設定好
    出現 ❌ 或 ⚠️ 怎麼辦

    照下面修改後，再按一次「② 一鍵設定與測試」。② 可以重複按，不會重複建立資料。

    訊息怎麼修
    USER_ID 不正確（代碼 400）回 STEP 3 重新複製「Your user ID」，用「① 填入金鑰」重填
    LINE_TOKEN 不正確（代碼 401）回 STEP 3 重新複製 Channel access token，用「① 填入金鑰」重填
    沒有權限（代碼 403）手機 LINE 還沒加官方帳號好友，回 STEP 2 第 4 小步
    Gemini 連線失敗多半是金鑰沒複製完整；寫「太久沒回應」就等一下再按一次
    Webhook 開關還沒打開官方帳號後台「回應設定」把 Webhook 切成啟用
    Webhook 設定失敗改用下方「手動設定 Webhook」
    手動設定 Webhook一鍵設定失敗才需要
    1. 官方帳號後台右上角「設定」→ 左側「Messaging API」，在「Webhook 網址」貼上 STEP 6 的網址，點「儲存」
    2. 或在 LINE Developers Console ↗「Messaging API」分頁的「Webhook settings」貼上，確認「Use webhook」已啟用
    3. 點「Verify」出現 302 Found 是正常的（Apps Script 會轉址，LINE 的驗證按鈕不支援），直接按「OK」
    在 Apps Script 編輯器手動建立觸發條件進階
    1. 函式下拉選單選 setupTriggers，點「執行」
    2. 左側鬧鐘圖示「觸發條件」，要看到 dailyMorningPush 和 checkTimedReminders 兩筆

    也可以選 testLinePush、testGemini 單獨測試 LINE 推播與 Gemini 連線，結果寫在下方「執行記錄」。

    FAQ 常見問題

    卡住時先查這裡

    點問題展開答案；也可以用關鍵字找，例如「Webhook」「提醒」「金鑰」。

    設定看不到「🤖 LINE 助理」選單？

    選單在最上方「說明」右邊。重新整理頁面等 5～10 秒；還是沒有，到「擴充功能」→「Apps Script」，函式選 onOpen 按執行，授權後切回試算表。

    設定LINE 傳訊息完全沒反應？
    1. 試算表「錯誤紀錄」分頁有沒有寫原因
    2. STEP 6「誰可以存取」是不是「所有人」
    3. 改過程式後有沒有部署「新版本」
    4. 官方帳號「回應設定」的 Webhook 是否啟用
    設定Verify 出現 302 Found？

    正常現象。Apps Script 會轉址，LINE 的驗證按鈕不支援，直接按「OK」，不影響運作。用 STEP 7 一鍵設定就不需要按 Verify。

    設定改了程式碼或流程規則，沒生效？

    只按儲存不會生效，要部署新版本：「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」。改 REMINDER_RULES 還要再按一次「② 一鍵設定與測試」。

    設定工作表名稱或欄位可以改嗎？

    名稱要和程式碼一字不差：「案件進度」「待辦與提醒」「收支紀錄」。欄位順序不能動，要加欄位請加在最後面。名稱打錯時，一鍵設定會自動補建。

    使用⏰ 提醒沒收到？
    1. Apps Script 左側「觸發條件」要有 dailyMorningPush 和 checkTimedReminders 兩筆，少了就按一次「② 一鍵設定與測試」
    2. 檢查每 5 分鐘一次，會在時間前 5～10 分鐘收到
    3. 超過時間 1 小時還沒推的，D 欄會標「已過期」，不補推
    使用回覆「AI 連線失敗」或「太久沒回應」？

    Gemini 免費方案在尖峰時段可能要等幾十秒甚至逾時，等一下再傳一次。有明確時間的提醒（例如「下午 3 點提醒我打電話」）不經過 Gemini，不受影響。一直失敗就看「錯誤紀錄」分頁。

    使用傳了新案件之後，想先記一筆帳？

    助理在等進度時，對不到階段的訊息會再問一次，不會被記成待辦或記帳。先回答進度（名稱或編號），或回「取消」放棄建檔。

    使用案件結案了怎麼處理？

    程式只推播 F 欄是「進行中」的案件。結案時把最後一列 F 欄改成「已完成」。更新進度時，舊列會自動改成「已更新」，不用手動改。

    使用一個官方帳號可以給整個團隊用嗎？

    不行。早上推播固定送給 User ID 那一個人。每個人各建一套：自己的官方帳號＋自己的試算表副本。

    費用要花錢嗎？
    • LINE 官方帳號「輕用量」月費 0 元，每月 200 則免費推播；AI 回覆你的訊息不算在內
    • 推播用量：早上推播每天最多 1 則，每個有時間的待辦再 1 則 ⏰。平均一天 6 則以內不會超過
    • Gemini API 免費方案超過上限只會暫時失敗，不會計費（Google Cloud 專案沒有啟用付費時）
    安全為什麼不能用公司對客戶的官方帳號？

    Webhook 是全域設定。一旦綁定，所有客戶私訊都會被攔截、送進 AI、記進你的試算表，客戶也收不到原本的自動回覆。

    安全客戶資料會傳給 Gemini 嗎？

    案件名稱、進度、金額會傳給 Gemini 判斷，Gemini 免費方案送出的內容 Google 可能用於改善產品。只傳案件代稱與進度，不要傳客戶姓名、電話、地址與報價明細。

    安全別人複製我的試算表，會用到我的金鑰嗎？

    不會。用選單填的金鑰只在當初填寫的那份試算表有效，副本會要求重新填，並清掉舊的金鑰。範本裡也沒有任何金鑰。

function doPost(e) {
  // 在編輯器直接按「執行」時沒有 LINE 訊息可讀，提醒一下就結束
  if (!e || !e.postData) {
    Logger.log('doPost 只會在 LINE 傳訊息進來時自動執行，不用手動執行。要測試請在 LINE 傳訊息給官方帳號。');
    return ContentService.createTextOutput('OK');
  }
  try {
    const json = JSON.parse(e.postData.contents);
    const events = json.events || [];
    const cache = CacheService.getScriptCache();

    for (const event of events) {
      const message = event.message;
      // 加好友、封鎖等不是訊息的事件，直接略過
      if (event.type !== 'message' || !message) continue;

      // 防止 LINE 重送同一則訊息造成重複記錄
      if (cache.get(message.id)) continue;
      cache.put(message.id, '1', 600);

      if (message.type === 'text') {
        handleUserText(message.text, event.replyToken);
      } else if (message.type === 'audio') {
        handleUserAudio(message.id, event.replyToken);
      }
    }
  } catch (err) {
    logError('doPost 出錯：' + err.message);
  }
  return ContentService.createTextOutput('OK');
}

/**
 * 處理使用者文字
 */
function handleUserText(userText, replyToken) {
  try {
    const props = PropertiesService.getScriptProperties();
    const pendingProject = props.getProperty('PENDING_PROJECT');
    const pendingDay = props.getProperty('PENDING_DAY');

    // 正在等使用者回答「下禮拜幾」
    if (pendingDay) {
      const ask = JSON.parse(pendingDay);
      const answer = String(userText).trim()
        .replace(/[０-９]/g, c => String.fromCharCode(c.charCodeAt(0) - 0xFEE0)) // 全形數字轉半形：２→2
        .replace(/^(是|在)?\s*(禮拜|星期|週|周)/, '');
      if (answer === '取消') {
        props.deleteProperty('PENDING_DAY');
        replyLine(replyToken, '好的，這筆不記了。');
        return;
      }
      // 把回答接回原本的句子再解析一次：「下禮拜」＋「三 下午兩點」→「下禮拜三 下午兩點」
      const merged = /^[一二三四五六日天1-7](?![\d\/月])/.test(answer) // 「3」是禮拜三，「11/20」是日期
        ? ask.text.replace(ask.matched, ask.matched + answer + ' ')
        : ask.text.replace(ask.matched, ' ' + answer + ' ');
      const todo = quickParseTodo(merged);
      if (todo && todo.type === 'TODO') {
        props.deleteProperty('PENDING_DAY');
        executeAction(todo, ask.text, replyToken);
        return;
      }
      replyLine(replyToken, `還沒收到是${ask.matched}幾喔！\n請回覆「三」或「禮拜三下午2點」，也可以回覆日期，例如「11/20」。\n\n不記了請回覆「取消」。`);
      return;
    }

    // 正在等使用者回答某個案件的進度
    if (pendingProject) {
      const text = String(userText).trim();
      if (text === '取消') {
        props.deleteProperty('PENDING_PROJECT');
        replyLine(replyToken, `已取消「${pendingProject}」的建檔。`);
        return;
      }
      const stage = matchStage(text);
      if (stage) {
        props.deleteProperty('PENDING_PROJECT');
        processProjectProgress(pendingProject, stage, replyToken);
        return;
      }
      // 對不到階段：不亂記，再問一次
      replyLine(replyToken, `還沒收到「${pendingProject}」的進度喔！\n請回覆階段名稱或編號：\n${stageMenu()}\n\n不建檔了請回覆「取消」。`);
      return;
    }

    // 「新案件」最常用，直接抓案件名稱，不用等 Gemini
    const quick = quickParseNewProject(userText);
    if (quick) {
      executeAction(quick, userText, replyToken);
      return;
    }

    // 「幾點提醒我…」「20 分鐘後…」這類有明確時間的待辦，直接解析，不用等 Gemini
    const quickTodo = quickParseTodo(userText);
    if (quickTodo && quickTodo.type === 'ASK_DAY') {
      // 只講「下禮拜」沒講禮拜幾：先問清楚再記
      props.setProperty('PENDING_DAY', JSON.stringify({ text: quickTodo.text, matched: quickTodo.matched }));
      replyLine(replyToken, `好的！請問是${quickTodo.matched}幾呢？\n請回覆「三」或「禮拜三下午2點」。\n\n不記了請回覆「取消」。`);
      return;
    }
    if (quickTodo) {
      executeAction(quickTodo, userText, replyToken);
      return;
    }

    // 使用 Gemini 判斷意圖（記下「處理中」，萬一 Gemini 卡住讓程式被中斷，定時檢查會通知使用者）
    const runKey = markAiStart(userText);
    const aiResult = analyzeIntentWithGemini(userText);
    markAiEnd(runKey);
    if (!aiResult) {
      replyLine(replyToken, lastGeminiError
        ? '⚠️ AI 連線失敗：' + lastGeminiError
        : '抱歉，我不太理解這則訊息，請再說一次。');
      return;
    }

    executeAction(aiResult, userText, replyToken);
  } catch (err) {
    logError('處理訊息出錯：' + err.message);
    replyLine(replyToken, '⚠️ 處理失敗：' + err.message);
  }
}

/**

function handleUserAudio(messageId, replyToken) {
  const audioBlob = fetchLineAudio(messageId);
  if (!audioBlob) {
    replyLine(replyToken, '語音讀取失敗，請稍後再試。');
    return;
  }

  const runKey = markAiStart('（語音訊息）');
  const transcribedText = speechToTextWithGemini(audioBlob);
  markAiEnd(runKey);
  if (!transcribedText) {
    replyLine(replyToken, lastGeminiError
      ? '⚠️ 語音辨識失敗：' + lastGeminiError + '\n\n語音一定要經過 AI，忙碌時建議先改用打字。'
      : '語音辨識不清楚，請重新發送或改用文字。');
    return;
  }

  // 辨識出文字後，直接走文字處理流程
  handleUserText(transcribedText, replyToken);
}

/**
 * 執行相應動作
 */
function executeAction(aiResult, rawText, replyToken) {
  switch (aiResult.type) {
    case 'NEW_PROJECT':
    case 'UPDATE_PROJECT': {
      const name = String(aiResult.projectName || '').trim();
      if (!name) {
        replyLine(replyToken, '請告訴我案件名稱，例如「我收到一個新案件：台中七期案」。');
        break;
      }
      // 訊息裡已經講了進度，就直接建檔或更新
      let stage = matchStage(aiResult.stage);
      if (!stage && aiResult.type === 'UPDATE_PROJECT') stage = matchStage(rawText);
      if (stage) {
        processProjectProgress(name, stage, replyToken);
        break;
      }
      // 還不知道進度：記下案件名稱，反問目前進度
      PropertiesService.getScriptProperties().setProperty('PENDING_PROJECT', name);
      const opening = aiResult.type === 'NEW_PROJECT' ? `收到新案件「${name}」！` : `要更新「${name}」的進度。`;
      replyLine(replyToken, `${opening}\n請問目前的進度是哪一個呢？請回覆階段名稱或編號：\n${stageMenu()}`);
      break;
    }

    case 'TODO': {
      const sheet = getSheet(SHEET_TODOS);
      const content = aiResult.content || rawText;
      const date = normalizeDate(aiResult.remindDate) || today();
      const time = normalizeTime(aiResult.remindTime);
      const remindText = time ? `${date} ${time}` : date;
      // 提醒時間存成純文字，避免試算表自動轉成別的日期格式
      appendRowAsText(sheet, [new Date(), content, remindText, '待推播'], [3]);
      const triggerWarning = ensureTriggers() ? '' : '\n\n⚠️ 提醒排程還沒啟用，請到 Apps Script 執行一次 setupTriggers';
      // 今天的早上推播已經過了，就不說「早上提醒一次」
      const morningPassed = date === today() && Number(Utilities.formatDate(new Date(), TZ, 'HH')) >= Number(REMINDER_RULES.morningHour);
      const when = time
        ? (morningPassed
          ? `${date} ${time} ${beforeText()}用 ⏰ 提醒`
          : `${date} 早上 ${REMINDER_RULES.morningHour} 點提醒一次，${time} ${beforeText()}再用 ⏰ 提醒`)
        : (morningPassed
          ? `${date}（今天早上的推播已經過了，記在今日待辦）`
          : `${date} 早上 ${REMINDER_RULES.morningHour} 點提醒`);
      replyLine(replyToken, `已為您建立待辦！\n事項：${content}\n提醒：${when}${triggerWarning}`);
      break;
    }

    case 'EXPENSE': {
      const sheet = getSheet(SHEET_EXPENSES);
      const amount = Number(String(aiResult.amount).replace(/[^\d.]/g, '')) || 0;
      const category = aiResult.category || '雜支';
      sheet.appendRow([new Date(), aiResult.item || rawText, amount, category]);
      replyLine(replyToken, `已記錄開銷！\n項目：${aiResult.item || rawText}\n金額：${amount} 元\n類別：${category}`);
      break;
    }

    default:
      replyLine(replyToken, `已收到：「${rawText}」\n若要記帳、待辦、建新案或更新案件進度，可直接語音或文字告訴我！`);
      break;
  }
}

/**
 * 處理案件進度並計算排程
 * 同一案件的舊紀錄會改成「已更新」，舊的提醒日就不會再推播
 */
function processProjectProgress(projectName, stage, replyToken) {
  const rule = WORKFLOW_RULES[stage];
  const targetDate = new Date();
  targetDate.setDate(targetDate.getDate() + rule.days);
  const dateString = Utilities.formatDate(targetDate, TZ, 'yyyy-MM-dd');

  const sheet = getSheet(SHEET_PROJECTS);
  const data = sheet.getDataRange().getValues();
  let isUpdate = false;
  for (let i = 1; i < data.length; i++) {
    if (String(data[i][1]).trim() === projectName && String(data[i][5]).trim() === '進行中') {
      sheet.getRange(i + 1, 6).setValue('已更新');
      isUpdate = true;
    }
  }

  appendRowAsText(sheet, [new Date(), projectName, stage, rule.nextAction, dateString, '進行中'], [5]);

  replyLine(replyToken, `「${projectName}」${isUpdate ? '進度已更新' : '已建檔'}！\n目前進度：${stage}\n下一步：${rule.nextAction}\n預計提醒日：${dateString}（${rule.days} 天後，當天早上推播）`);
}

/**
 * 呼叫 Gemini 進行意圖分析
 */
function analyzeIntentWithGemini(userText) {
  const now = Utilities.formatDate(new Date(), TZ, 'yyyy-MM-dd HH:mm（EEEE）');
  const stageList = Object.keys(WORKFLOW_RULES).join('、');

  const prompt = [
    `你是一個案件與行程秘書。現在的台灣時間是 ${now}。`,
    '請判斷使用者訊息屬於哪一類，只回傳一個 JSON 物件，不要加任何說明或 markdown 標記。',
    '',
    '1. 新案件：{"type": "NEW_PROJECT", "projectName": "案件名稱", "stage": "訊息有提到的階段，沒提到填空字串"}',
    '2. 更新既有案件的進度（例如「台中七期案已經簽約了」）：{"type": "UPDATE_PROJECT", "projectName": "案件名稱", "stage": "新的階段"}',
    '3. 待辦提醒：{"type": "TODO", "content": "待辦事項文字", "remindDate": "yyyy-MM-dd", "remindTime": "HH:mm 或空字串"}',
    '4. 記帳開銷：{"type": "EXPENSE", "item": "品項名稱", "amount": 數字, "category": "交通費/餐費/材料費/雜支"}',
    '5. 其他：{"type": "OTHER"}',
    '',
    '規則：',
    `- stage 只能填這些階段之一：${stageList}；對不到就填空字串。`,
    '- remindDate 請依現在時間換算成實際日期（「明天」「下週一」都要換成 yyyy-MM-dd）；沒提到日期就填今天。',
    '- remindTime 用 24 小時制（「下午兩點」填 14:00）；沒提到時間就填空字串。',
    '- amount 只填數字，不要加「元」。',
    '',
    `使用者訊息：${userText}`
  ].join('\n');

  const text = callGemini([{ text: prompt }], { responseMimeType: 'application/json' });
  if (!text) return null;
  try {
    const match = text.match(/\{[\s\S]*\}/);
    return JSON.parse(match ? match[0] : text);
  } catch (err) {
    Logger.log('Gemini 回傳的不是 JSON：' + text);
    return null;
  }
}

/**

 */
function fetchLineAudio(messageId) {
  const url = `https://api-data.line.me/v2/bot/message/${messageId}/content`;
  try {
    const res = UrlFetchApp.fetch(url, {
      headers: { 'Authorization': `Bearer ${getKey('LINE_TOKEN')}` },
      muteHttpExceptions: true
    });
    if (res.getResponseCode() !== 200) {
      Logger.log('下載語音失敗，代碼 ' + res.getResponseCode());
      return null;
    }
    return res.getBlob();
  } catch (err) {
    Logger.log('Fetch Line Audio Error: ' + err.message);
    return null;
  }
}

/**
 * 呼叫 Gemini（金鑰放在 header，不放在網址，避免出錯時金鑰出現在紀錄裡）
 * 模型下架（代碼 404）時，會自動找一個這組金鑰能用的 Flash 模型重試，並記住下次直接用
 */
function callGemini(parts, generationConfig) {
  const body = { contents: [{ parts: parts }] };
  if (generationConfig) body.generationConfig = generationConfig;
  lastGeminiError = '';
  if (!getKey('GEMINI_API_KEY')) {
    lastGeminiError = '還沒填 Gemini API Key，請用試算表選單「🤖 LINE 助理」→「① 填入金鑰」';
    return null;
  }

  const startedAt = Date.now();
  try {
    let model = currentGeminiModel();
    // 這個模型最近很慢或卡住過：15 分鐘內先用備用模型
    if (CacheService.getScriptCache().get('GEMINI_SLOW_' + model)) {
      const backup = findBackupModel(model);
      if (backup) {
        Logger.log(`模型「${model}」最近很慢，這次先用「${backup}」`);
        model = backup;
      }
    }
    let res = requestGemini(model, body);
    if (Date.now() - startedAt > 30000) markModelSlow(model);

    if (res.getResponseCode() === 404) {
      const found = findAvailableModel();
      if (found && found !== model) {
        Logger.log(`模型「${model}」找不到，自動改用「${found}」`);
        PropertiesService.getScriptProperties().setProperty('GEMINI_MODEL_AUTO', JSON.stringify({ from: GEMINI_MODEL, to: found }));
        model = found;
        res = requestGemini(model, body);
      }
    }

    // 伺服器忙碌（503 等）：等 1.5 秒重試一次；還是不行就依序改用最多 3 個備用模型（不會記住，下次仍用原本的模型）
    // 已經等超過 45 秒就不再重試，避免使用者等太久
    const busy = c => c === 500 || c === 502 || c === 503 || c === 504;
    const canRetry = () => Date.now() - startedAt < 45000;
    const tried = [`${model} ${res.getResponseCode()}`];
    if (busy(res.getResponseCode()) && canRetry()) {
      Utilities.sleep(1500);
      res = requestGemini(model, body);
      tried.push(`${model} 重試 ${res.getResponseCode()}`);
    }
    if (busy(res.getResponseCode()) || res.getResponseCode() === 429) {
      const backups = findBackupModels(model).slice(0, 3);
      if (!backups.length) tried.push('找不到備用模型');
      for (const backup of backups) {
        if (!canRetry()) { tried.push('超過 45 秒，停止重試'); break; }
        const backupRes = requestGemini(backup, body);
        tried.push(`${backup} ${backupRes.getResponseCode()}`);
        if (backupRes.getResponseCode() === 200) {
          Logger.log('Gemini 改用備用模型成功：' + tried.join(' → '));
          return parseGeminiText(backupRes);
        }
      }
    }

    const code = res.getResponseCode();
    if (code !== 200) {
      logError(`Gemini 回應錯誤（代碼 ${code}，試過：${tried.join(' → ')}）：` + res.getContentText().slice(0, 300));
      const hints = {
        400: 'API Key 格式不對，請重新複製 Google AI Studio 的金鑰，用選單「① 填入金鑰」重填',
        401: 'API Key 不正確，請重新複製金鑰，用選單「① 填入金鑰」重填',
        403: 'API Key 沒有權限，請確認金鑰是在 Google AI Studio 建立的',
        404: `找不到可用的 Gemini 模型，請在編輯器執行 listGeminiModels 查看可用名稱，填進 GEMINI_MODEL`,
        429: '超過免費額度或傳太快，請等一分鐘再試',
        500: 'Gemini 暫時出錯，已自動重試和換模型都沒成功，請過一兩分鐘再傳一次',
        503: 'Gemini 現在使用的人太多，已自動重試和換模型都沒成功，請過一兩分鐘再傳一次。有明確時間的提醒（例如「下午3點提醒我打電話」）不受影響'
      };
      lastGeminiError = `（代碼 ${code}）` + (hints[code] || hints[busy(code) ? 503 : 0] || '請到 Apps Script 編輯器執行 testGemini 查看詳細紀錄');
      return null;
    }
    return parseGeminiText(res);
  } catch (err) {
    const msg = String(err.message).replace(/https?:\/\/\S+/g, '').trim();
    logError('Gemini 連線錯誤：' + msg);
    lastGeminiError = /timeout|timed out|タイムアウト|逾時|超時/i.test(msg)
      ? 'Gemini 太久沒回應，請再傳一次。有明確時間的提醒（例如「下午3點提醒我打電話」）不用等 Gemini'
      : '連線錯誤：' + msg;
    return null;
  }
}

// 取出 Gemini 回覆的文字
function parseGeminiText(res) {
  const data = JSON.parse(res.getContentText());
  const text = data.candidates?.[0]?.content?.parts?.[0]?.text;
  return text ? text.trim() : null;
}

// 備用模型：原本的模型忙碌時臨時改用。挑其他 Flash 模型（可含 Lite），由新到舊排好，模型清單快取 6 小時
function findBackupModel(current) {
  return findBackupModels(current)[0] || '';
}

function findBackupModels(current) {
  const cache = CacheService.getScriptCache();
  let names;
  const cached = cache.get('GEMINI_MODEL_LIST');
  if (cached) {
    try { names = JSON.parse(cached); } catch (err) {}
  }
  if (!names) {
    names = fetchGeminiModels();
    if (names.length) cache.put('GEMINI_MODEL_LIST', JSON.stringify(names), 21600);
  }
  const version = n => parseFloat((n.match(/gemini-(\d+(?:\.\d+)?)/) || [])[1] || 0);
  return names
    .filter(n => n !== current && /^gemini-.*flash/.test(n))
    .filter(n => !/(image|tts|live|audio|embed|exp|thinking)/.test(n))
    .sort((a, b) => (/preview/.test(a) - /preview/.test(b)) || (version(b) - version(a)) || (/lite/.test(a) - /lite/.test(b)) || (a.length - b.length));
}

// 送出一次 Gemini 請求：思考程度由低到高試（minimal → low → 不指定），記住這個模型能用的最低程度，回應最快
function requestGemini(model, body) {
  const props = PropertiesService.getScriptProperties();
  const propKey = 'GEMINI_THINKING_' + model;
  const saved = props.getProperty(propKey);
  const levels = saved ? [saved] : ['minimal', 'low', 'none'];
  const send = b => UrlFetchApp.fetch(`https://generativelanguage.googleapis.com/v1beta/models/${model}:generateContent`, {
    method: 'post',
    contentType: 'application/json',
    headers: { 'x-goog-api-key': getKey('GEMINI_API_KEY') },
    payload: JSON.stringify(b),
    muteHttpExceptions: true
  });

  const started = Date.now();
  let res;
  for (const level of levels) {
    const b = JSON.parse(JSON.stringify(body));
    if (level !== 'none') {
      b.generationConfig = Object.assign({}, b.generationConfig, { thinkingConfig: { thinkingLevel: level } });
    }
    res = send(b);
    const rejected = res.getResponseCode() === 400 && /thinking/i.test(res.getContentText());
    if (rejected) continue;
    if (!saved && res.getResponseCode() === 200) props.setProperty(propKey, level);
    break;
  }

  const seconds = (Date.now() - started) / 1000;
  if (seconds > 15) logError(`Gemini 回應很慢：${seconds.toFixed(1)} 秒（模型 ${model}）`);
  return res;
}

// 目前要用的模型：之前自動換過就用換過的，否則用 GEMINI_MODEL
function currentGeminiModel() {
  const saved = PropertiesService.getScriptProperties().getProperty('GEMINI_MODEL_AUTO');
  if (saved) {
    try {
      const s = JSON.parse(saved);
      if (s.from === GEMINI_MODEL && s.to) return s.to;
    } catch (err) {}
  }
  return GEMINI_MODEL;
}

// 取得這組金鑰能用的模型清單
function fetchGeminiModels() {
  const res = UrlFetchApp.fetch('https://generativelanguage.googleapis.com/v1beta/models?pageSize=1000', {
    headers: { 'x-goog-api-key': getKey('GEMINI_API_KEY') },
    muteHttpExceptions: true
  });
  if (res.getResponseCode() !== 200) {
    Logger.log('查詢模型清單失敗（代碼 ' + res.getResponseCode() + '）：' + res.getContentText().slice(0, 300));
    return [];
  }
  return (JSON.parse(res.getContentText()).models || [])
    .filter(m => (m.supportedGenerationMethods || []).includes('generateContent'))
    .map(m => m.name.replace('models/', ''));
}

// 自動挑一個可用的 Flash 模型：優先正式版、版本號最新的
function findAvailableModel() {
  const names = fetchGeminiModels();
  const version = n => parseFloat((n.match(/gemini-(\d+(?:\.\d+)?)/) || [])[1] || 0);
  const flash = names
    .filter(n => /^gemini-.*flash/.test(n))
    .filter(n => !/(lite|image|tts|live|audio|embed|exp|thinking)/.test(n))
    .sort((a, b) => (/preview/.test(a) - /preview/.test(b)) || (version(b) - version(a)) || (a.length - b.length));
  return flash[0] || names.find(n => /^gemini-/.test(n)) || '';
}

/**
 * 回覆 LINE 訊息
 */
function replyLine(replyToken, messageText) {
  const res = UrlFetchApp.fetch('https://api.line.me/v2/bot/message/reply', {
    method: 'post',
    headers: {
      'Content-Type': 'application/json; charset=UTF-8',
      'Authorization': `Bearer ${getKey('LINE_TOKEN')}`
    },
    payload: JSON.stringify({ replyToken: replyToken, messages: [{ type: 'text', text: messageText }] }),
    muteHttpExceptions: true
  });
  if (res.getResponseCode() === 200) return;
  // AI 回應太慢，回覆憑證（約 1 分鐘有效）已過期：改用推播把結果送出去
  if (res.getResponseCode() === 400 && /reply token/i.test(res.getContentText())) {
    Logger.log('回覆憑證已過期，改用推播送出結果');
    pushLine(messageText);
    return;
  }
  logError(`LINE 回覆失敗（代碼 ${res.getResponseCode()}）：` + res.getContentText().slice(0, 300));
}

/**
 * 主動推播訊息給使用者
 */
function pushLine(messageText) {
  const res = UrlFetchApp.fetch('https://api.line.me/v2/bot/message/push', {
    method: 'post',
    headers: {
      'Content-Type': 'application/json; charset=UTF-8',
      'Authorization': `Bearer ${getKey('LINE_TOKEN')}`
    },
    payload: JSON.stringify({ to: getKey('USER_ID'), messages: [{ type: 'text', text: messageText }] }),
    muteHttpExceptions: true
  });
  if (res.getResponseCode() !== 200) logError(`LINE 推播失敗（代碼 ${res.getResponseCode()}）：` + res.getContentText().slice(0, 300));
  return res.getResponseCode();
}

/**
 * 每天早上定時推播（時間在 REMINDER_RULES.morningHour 設定）：今天的待辦＋今天到期的案件
 */
function dailyMorningPush() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const todayStr = today();
  const sections = [];

  // 1. 今日待辦
  const sheetTodo = ss.getSheetByName(SHEET_TODOS);
  if (sheetTodo) {
    const data = sheetTodo.getDataRange().getValues();
    const todos = [];
    for (let i = 1; i < data.length; i++) {
      const remind = parseRemind(data[i][2]);
      const status = String(data[i][3]).trim();
      if (remind.date !== todayStr || status === '已完成') continue;
      todos.push(`• ${data[i][1]}${remind.time ? `（${remind.time}）` : ''}`);
      // 沒有指定時間的待辦，早上推過就算完成；有時間的會再由 checkTimedReminders 提前提醒
      if (!remind.time && status === '待推播') sheetTodo.getRange(i + 1, 4).setValue('已推播');
    }
    if (todos.length > 0) sections.push(`【今日待辦事項】\n${todos.join('\n')}`);
  }

  // 2. 今日到期的案件跟進
  const sheetProject = ss.getSheetByName(SHEET_PROJECTS);
  if (sheetProject) {
    const pData = sheetProject.getDataRange().getValues();
    const projects = [];
    for (let i = 1; i < pData.length; i++) {
      const remindDate = parseRemind(pData[i][4]).date;
      const status = String(pData[i][5]).trim();
      if (remindDate === todayStr && status === '進行中') {
        projects.push(`• ${pData[i][1]}：需進行「${pData[i][3]}」`);
      }
    }
    if (projects.length > 0) sections.push(`【今日案件跟進】\n${projects.join('\n')}`);
  }

  if (sections.length === 0) {
    Logger.log('今天沒有待辦或到期案件，不推播。');
    return false;
  }
  pushLine(`☀️ 早上好！今日（${todayStr}）重點提醒：\n\n${sections.join('\n\n')}`);
  return true;
}

/**
 * 定時檢查：有指定時間的待辦，在時間前 REMINDER_RULES.minutesBefore 分鐘用 ⏰ 提醒
 */
function checkTimedReminders() {
  checkStuckAi();
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(SHEET_TODOS);
  if (!sheet) return;

  const now = Date.now();
  const todayStr = today();
  const before = Math.max(0, Number(REMINDER_RULES.minutesBefore) || 0);
  const data = sheet.getDataRange().getValues();

  for (let i = 1; i < data.length; i++) {
    if (String(data[i][3]).trim() !== '待推播') continue;
    const remind = parseRemind(data[i][2]);
    if (!remind.date) continue;

    if (!remind.time) {
      // 沒有時間的待辦由早上推播負責；日期已過還沒推，標記起來不再補推
      if (remind.date < todayStr) sheet.getRange(i + 1, 4).setValue('已過期');
      continue;
    }

    const remindAt = new Date(`${remind.date}T${remind.time}:00+08:00`).getTime();
    if (now > remindAt + 60 * 60 * 1000) {
      // 已經超過時間一小時還沒推（例如觸發條件當時沒開），不再補推
      sheet.getRange(i + 1, 4).setValue('已過期');
    } else if (now >= remindAt - before * 60 * 1000) {
      const left = Math.round((remindAt - now) / 60000);
      const head = left > 0 ? `⏰ 再 ${left} 分鐘：` : '⏰ 時間到囉：';
      // 推播成功才標記；失敗的話下次檢查會再試一次
      if (pushLine(`${head}\n${data[i][1]}（${remind.time}）`) === 200) sheet.getRange(i + 1, 4).setValue('已推播');
    }
  }
}

// 記下「AI 處理中」：Apps Script 一次最多跑 6 分鐘，Gemini 卡住時程式會被直接中斷、來不及回覆
function markAiStart(label) {
  const key = 'AI_RUN_' + Date.now() + '_' + Math.floor(Math.random() * 1000);
  PropertiesService.getScriptProperties().setProperty(key, JSON.stringify({ label: String(label).slice(0, 100), at: Date.now(), model: currentGeminiModel() }));
  return key;
}

function markAiEnd(key) {
  PropertiesService.getScriptProperties().deleteProperty(key);
}

// 定時檢查時順便看：有沒有超過 7 分鐘還沒結束的 AI 處理（代表被中斷了），通知使用者再傳一次
function checkStuckAi() {
  const props = PropertiesService.getScriptProperties();
  const all = props.getProperties();
  Object.keys(all).filter(k => k.indexOf('AI_RUN_') === 0).forEach(k => {
    let run;
    try { run = JSON.parse(all[k]); } catch (err) { props.deleteProperty(k); return; }
    if (Date.now() - run.at < 7 * 60 * 1000) return;
    props.deleteProperty(k);
    markModelSlow(run.model);
    logError(`Gemini 卡住超過 6 分鐘，程式被中斷（模型 ${run.model}）：${run.label}`);
    pushLine(`⚠️ 剛剛這則訊息 AI 處理太久，被系統中斷，沒有記錄到：\n「${run.label}」\n\n請再傳一次，接下來會自動改用備用模型。`);
  });
}

// 模型回應很慢：接下來 15 分鐘先改用備用模型
function markModelSlow(model) {
  if (model) CacheService.getScriptCache().put('GEMINI_SLOW_' + model, '1', 900);
}

/**
 * 一次建立兩個觸發條件（執行一次即可，重複執行會先清掉舊的）
 * 改了 REMINDER_RULES 之後，要再執行一次才會生效
 */
function setupTriggers() {
  const hour = Math.min(23, Math.max(0, parseInt(REMINDER_RULES.morningHour, 10) || 7));
  const allowed = [1, 5, 10, 15, 30];
  const every = allowed.includes(Number(REMINDER_RULES.checkEveryMinutes)) ? Number(REMINDER_RULES.checkEveryMinutes) : 5;

  ScriptApp.getProjectTriggers().forEach(t => ScriptApp.deleteTrigger(t));
  ScriptApp.newTrigger('dailyMorningPush').timeBased().everyDays(1).atHour(hour).inTimezone(TZ).create();
  ScriptApp.newTrigger('checkTimedReminders').timeBased().everyMinutes(every).create();

// 把這個專案的網頁應用程式網址設成 LINE 的 Webhook，並確認 Webhook 開關有打開

    url = '';
  }

    url = res.getResponseText().trim();
  }
  if (!/^https:\/\/script\.google\.com\/.+\/exec$/.test(url)) {
    return '❌ Webhook 網址格式不對：要是 https://script.google.com/ 開頭、/exec 結尾';

  const headers = { 'Authorization': `Bearer ${getKey('LINE_TOKEN')}` };
  const put = UrlFetchApp.fetch('https://api.line.me/v2/bot/channel/webhook/endpoint', {
    method: 'put',
    contentType: 'application/json',
    headers: headers,
    payload: JSON.stringify({ endpoint: url }),
    muteHttpExceptions: true
  });
  if (put.getResponseCode() !== 200) {
    logError(`設定 Webhook 失敗（代碼 ${put.getResponseCode()}）：` + put.getContentText().slice(0, 300));
    return `❌ Webhook 設定失敗（代碼 ${put.getResponseCode()}），請改到 LINE Official Account Manager「Messaging API」手動貼上網址`;
  }

  const get = UrlFetchApp.fetch('https://api.line.me/v2/bot/channel/webhook/endpoint', { headers: headers, muteHttpExceptions: true });

// 檢查金鑰格式，常見的複製錯誤先擋下來

  return '';
}

// 抓「新案件」訊息：例如「我收到一個新案件：台中七期案」「新案子 信義案，報價了」
function quickParseNewProject(text) {

  if (!m) return null;

}

// 抓待辦的日期和時間，不用等 Gemini：
// 「提醒我今天8:30要打電話給A」「明天下午兩點去工地丈量」「20分鐘後提醒我關電燈」「下禮拜三提醒我去台南看場地」
// 只講「下禮拜」沒講禮拜幾，回傳 ASK_DAY，由助理反問；抓不到日期和時間就回傳 null，交給 Gemini 判斷
function quickParseTodo(text) {
  let t = String(text).replace(/[０-９]/g, c => String.fromCharCode(c.charCodeAt(0) - 0xFEE0))
    .replace(/：/g, ':').trim();
  if (/\d\s*(元|塊|圓)/.test(t)) return null; // 有金額的是記帳

  const NUM = '(\\d{1,3}|[零〇一二兩三四五六七八九十]{1,3})';
  const TODO_WORDS = /(提醒|記得|別忘|待辦|要|得|需要|去)/;
  const now = new Date();
  let date = '', time = '', removed = [];

  // 相對時間：「20分鐘後」「半小時後」「2小時後」
  let when = null, m;
  if ((m = t.match(new RegExp(NUM + '\\s*分鐘(?:之)?後')))) when = new Date(now.getTime() + zhNumber(m[1]) * 60000);
  else if ((m = t.match(/半(?:個)?小時(?:之)?後/))) when = new Date(now.getTime() + 30 * 60000);
  else if ((m = t.match(new RegExp(NUM + '\\s*(?:個)?(?:小時|鐘頭)(?:之)?後')))) when = new Date(now.getTime() + zhNumber(m[1]) * 3600000);

  if (when) {
    date = Utilities.formatDate(when, TZ, 'yyyy-MM-dd');
    time = Utilities.formatDate(when, TZ, 'HH:mm');
    removed.push(m[0]);
  } else {
    // 日期：今天、明天、後天、下禮拜三、週五、11月20日、11/20
    const day = findDay(t);
    if (day && day.ask) {
      return TODO_WORDS.test(t) ? { type: 'ASK_DAY', text: t, matched: day.matched } : null;
    }
    const rest = day ? t.replace(day.matched, ' ') : t;

    // 時間：早上8:30、八點半、下午兩點十分
    m = rest.match(new RegExp('(凌晨|早上|上午|中午|下午|傍晚|晚上)?\\s*' + NUM + '\\s*(?::\\s*(\\d{2})|點\\s*(半|' + NUM + '\\s*分?)?)'));
    if (!m) {
      // 只有日期、沒講幾點：要有「提醒、要、去」這類字才算待辦（避免「明天天氣如何」被當成待辦）
      if (!day || !TODO_WORDS.test(t)) return null;
      date = day.date;
      removed.push(day.matched);
    } else {
      const [whole, period, hourText, minDigits, pointMin] = m;
      let hour = zhNumber(hourText);
      const min = minDigits ? parseInt(minDigits, 10) : pointMin === '半' ? 30 : pointMin ? zhNumber(pointMin.replace(/分$/, '').trim()) : 0;
      if (/下午|傍晚|晚上/.test(period || '') && hour < 12) hour += 12;
      if (period === '中午' && hour < 11) hour += 12;
      if (isNaN(hour) || isNaN(min) || hour > 23 || min > 59) return null;
      date = day ? day.date : today();
      time = `${String(hour).padStart(2, '0')}:${String(min).padStart(2, '0')}`;

      // 沒講哪一天、時間已經過了：沒講上下午就當成下午，否則算明天
      if (!day) {
        const nowText = Utilities.formatDate(now, TZ, 'HH:mm');
        if (time <= nowText) {
          const pm = `${String(hour + 12).padStart(2, '0')}:${String(min).padStart(2, '0')}`;
          if (!period && hour < 12 && pm > nowText) time = pm;
          else date = shiftDate(today(), 1);
        }
      }
      if (day) removed.push(day.matched);
      removed.push(whole);
    }
  }

  let content = t;
  removed.forEach(r => { content = content.replace(r, ' '); });
  content = content
    .replace(/(請)?(幫我)?(提醒我|提醒一下|提醒|記得|別忘了|別忘記)/g, ' ')
    .replace(/^[\s，,。]+|[\s，,。！!]+$/g, '')
    .replace(/\s+/g, ' ')
    .replace(/^(要|再)\s*/, '')
    .trim();
  if (!content) return null;
  return { type: 'TODO', content: content, remindDate: date, remindTime: time };
}

// 找出訊息裡的日期。回傳 { date, matched }；只講「下禮拜」沒講禮拜幾，回傳 { ask: true, matched }
function findDay(t) {
  const re = /(大後天|今天|今日|明天|明日|後天|(下下|下|這|本)?個?(?:禮拜|星期|週|周)([一二三四五六日天1-7])?|(\d{1,2})\s*[月\/]\s*(\d{1,2})\s*[日號]?)/g;
  const base = today();
  let m;
  while ((m = re.exec(t))) {
    const [whole, word, prefix, wd, mon, day] = m;
    if (mon && day) {
      const y = parseInt(base.slice(0, 4), 10);
      const target = `${y}-${String(mon).padStart(2, '0')}-${String(day).padStart(2, '0')}`;
      return { date: target < base ? `${y + 1}${target.slice(4)}` : target, matched: whole };
    }
    const fixed = { 今天: 0, 今日: 0, 明天: 1, 明日: 1, 後天: 2, 大後天: 3 }[word];
    if (fixed !== undefined) return { date: shiftDate(base, fixed), matched: whole };
    if (!wd) {
      if (prefix) return { ask: true, matched: whole };
      continue; // 只有「週」這個字（例如「週報」），不是日期
    }
    // 禮拜幾：一＝1 … 日＝7
    const w = /\d/.test(wd) ? Number(wd) : /[日天]/.test(wd) ? 7 : '一二三四五六'.indexOf(wd) + 1;
    const dow = new Date(base + 'T12:00:00Z').getUTCDay() || 7; // 今天禮拜幾
    let offset;
    if (prefix === '下') offset = 7 - dow + w;
    else if (prefix === '下下') offset = 14 - dow + w;
    else offset = (w - dow + 7) % 7; // 「這禮拜三」「週三」：最近的那個禮拜三（今天就是今天）
    return { date: shiftDate(base, offset), matched: whole };
  }
  return null;
}

// 日期加減天數：shiftDate('2026-11-12', 1) → '2026-11-13'
function shiftDate(dateStr, days) {
  const d = new Date(new Date(dateStr + 'T12:00:00+08:00').getTime() + days * 86400000);
  return Utilities.formatDate(d, TZ, 'yyyy-MM-dd');
}

// 中文或阿拉伯數字轉數字（支援到 99）：兩→2、十→10、十五→15、二十→20、三十五→35
function zhNumber(text) {
  const s = String(text).trim();
  if (/^\d+$/.test(s)) return parseInt(s, 10);
  const map = { 零: 0, 〇: 0, 一: 1, 二: 2, 兩: 2, 三: 3, 四: 4, 五: 5, 六: 6, 七: 7, 八: 8, 九: 9 };
  if (s.indexOf('十') === -1) return map[s] !== undefined ? map[s] : NaN;
  const [tens, ones] = s.split('十');
  return (tens ? map[tens] : 1) * 10 + (ones ? map[ones] : 0);
}

// 提醒文字：「前 10 分鐘」或「時間到時」

// 把使用者的回答對到階段：支援編號、完整名稱、省略「已」的說法（例如「簽約了」）
function matchStage(input) {
  if (!input) return '';
  const stages = Object.keys(WORKFLOW_RULES);
  const text = String(input).trim().replace(/[０-９]/g, c => String.fromCharCode(c.charCodeAt(0) - 0xFEE0));

  if (/^\d{1,2}\.?$/.test(text)) {
    return stages[parseInt(text, 10) - 1] || '';
  }

  const byLength = stages.slice().sort((a, b) => b.length - a.length);
  for (const s of byLength) {
    if (text.includes(s)) return s;
  }
  for (const s of byLength) {
    const core = s.replace(/^已/, '');
    if (core !== s && text.includes(core)) return s;
  }
  return '';
}

// 各種日期寫法統一成 yyyy-MM-dd
function normalizeDate(value) {
  if (!value) return '';
  if (value instanceof Date) return Utilities.formatDate(value, TZ, 'yyyy-MM-dd');
  const m = String(value).match(/(\d{4})[-\/.](\d{1,2})[-\/.](\d{1,2})/);
  return m ? `${m[1]}-${m[2].padStart(2, '0')}-${m[3].padStart(2, '0')}` : '';
}

// 各種時間寫法統一成 HH:mm，沒有時間回傳空字串
function normalizeTime(value) {
  if (!value) return '';
  const m = String(value).match(/(\d{1,2}):(\d{2})/);
  if (!m) return '';
  const h = parseInt(m[1], 10);
  const min = parseInt(m[2], 10);
  if (h > 23 || min > 59) return '';
  return `${String(h).padStart(2, '0')}:${m[2]}`;
}

// 讀取試算表裡的提醒時間（文字或日期格式都能讀）
function parseRemind(value) {
  if (value instanceof Date) {
    const time = Utilities.formatDate(value, TZ, 'HH:mm');
    return { date: Utilities.formatDate(value, TZ, 'yyyy-MM-dd'), time: time === '00:00' ? '' : time };
  }
  return { date: normalizeDate(value), time: normalizeTime(value) };
}
